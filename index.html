Technology

Modern tools, chosen per product.

KivuStack works with modern software technologies and selects tools based on the requirements of each product. No single fixed stack is assumed for all projects.

No fabricated stack.

We do not publish an arbitrary technology list for the whole company. The correct stack is decided per product and documented where the product lives.

  • Maintainability first — we prioritize code that is easy to understand and evolve.
  • Security & developer experience — safe defaults and clear documentation.
  • Documented choices — every product repository explains its own technology decisions.
