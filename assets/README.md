# Assets — KivuSoft Ltd

This directory contains the official **KivuSoft Ltd** visual identity and brand assets.

## Logo system

| File | Purpose | Background |
|------|---------|------------|
| `kivusoft-logo.svg` | Primary logo — icon + `KivuSoft` wordmark | Light (`#ffffff`) |
| `kivusoft-logo-dark.svg` | Logo variant for dark backgrounds | Dark (`#0b1020`) |
| `kivusoft-icon.svg` | Icon only — favicon, small spaces | Light |
| `kivusoft-icon-dark.svg` | Icon only — for dark backgrounds | Dark |

All logos are original, editable SVGs (`viewBox`, no external dependencies, no scripts) with a clean geometric **K** mark. The wordmark reads exactly `KivuSoft` (the `Ltd` appears in supporting lockups such as the Open Graph image and footer, not the main mark).

Deployed copies for the website are in `website/assets/images/` and are kept in sync.

## Brand guidelines

`brand-guidelines.md` — palette (HEX), typography (system‑first), logo usage, favicon, OG image, current status, and licensing separation. This is the current KivuSoft Ltd brand identity (2026).

## Additional assets

* `website/assets/images/favicon.svg` — official favicon derived from the icon
* `website/assets/images/og-image.svg` — 1200×630 social preview graphic with `KivuSoft Ltd` and company descriptor

## Usage

* Use `kivusoft-logo.svg` on light backgrounds, `-dark.svg` on dark
* Maintain clear space around the logo equal to the height of the `K` stem
* Do not stretch, rotate, add effects, or recolor outside the approved palette
* Only commit assets approved by **KivuSoft Ltd**
* Branding assets are not automatically covered by the repository MIT license — see `brand-guidelines.md` for licensing separation
