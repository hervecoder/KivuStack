# Contributing to KivuSoft Ltd

Thank you for your interest in contributing to the **KivuSoft Ltd** company hub. This repository is the official public identity for KivuSoft Ltd and contains company documentation and hub resources.

## Before contributing

- Read the repository `README.md` to understand the purpose of this repository.
- Understand that this repository is for company identity and documentation — not for product-specific code.
- Search existing issues and discussions before creating a new one to avoid duplicates.

## Contributions

We welcome:

- **Bug reports** — clear descriptions of errors in documentation or configuration
- **Documentation improvements** — corrections, clarity, or factual updates
- **Suggestions** — ideas for improving the company hub presentation or structure
- **Code or content contributions** where applicable — focused improvements to this repository

Please do not submit speculative product code or unverified claims about the company.

## Pull requests

When submitting a pull request:

- Make focused, single-purpose changes
- Clearly describe what changed and why
- Avoid unrelated modifications in the same pull request
- Ensure documentation remains accurate and links remain valid
- Do not commit secrets, credentials, API keys, tokens, or private information
- Keep changes consistent with the existing style and terminology (`KivuSoft Ltd`)

## Quality

We value:

- **Clarity** — easy to read and understand
- **Maintainability** — simple and sustainable
- **Security** — no sensitive data, safe defaults
- **Respectful collaboration** — constructive feedback and professional communication

There is no complex development workflow for this hub repository. Small documentation changes may be made directly via pull request to `main`. Larger changes should be discussed in an issue first.

Thank you for helping improve KivuSoft Ltd.
