# Images

This directory is reserved for official **KivuSoft Ltd** website images.

## Current state

No binary images are committed yet. The website uses a lightweight text-based wordmark and CSS-driven visuals to avoid external dependencies and stock-image usage.

## Intended contents

- Official logo files (when approved)
- Approved product or team imagery
- Icons and illustrations owned by KivuSoft Ltd

## Guidelines

- Use optimized formats (SVG preferred for logos/icons, WebP/AVIF for photos where appropriate)
- Keep files small and accessible (provide `alt` text where used)
- Only commit assets owned or licensed by KivuSoft Ltd
