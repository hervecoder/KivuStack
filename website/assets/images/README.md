# Website Images — KivuStack Ltd

This directory contains official **KivuStack Ltd** website images deployed to GitHub Pages.

## Current assets

* `favicon.svg` — 32×32 KivuStack icon favicon (based on `KivuStack-icon.svg`), `type="image/svg+xml"`
* `og-image.svg` — 1200×630 social preview graphic with `KivuStack Ltd` and descriptor “Useful, reliable, and accessible technology”
* `KivuStack-logo.svg` — primary logo (icon + `KivuStack` wordmark) for light backgrounds
* `KivuStack-logo-dark.svg` — logo variant for dark backgrounds
* `KivuStack-icon.svg` / `KivuStack-icon-dark.svg` — icon-only variants

All files are copies of the canonical assets in `/assets/` (`KivuStack-logo.svg`, `KivuStack-logo-dark.svg`, `KivuStack-icon.svg`, `KivuStack-icon-dark.svg`) and are kept in sync for deployment. The canonical brand documentation is `assets/brand-guidelines.md`.

## Intended contents

* Official logo files (approved)
* Approved product or team imagery
* Icons and illustrations owned by KivuStack Ltd
* Social preview images

## Guidelines

* Use optimized formats (SVG preferred for logos/icons, WebP/AVIF for photos where appropriate)
* Keep files small and accessible (provide `alt` text where used)
* Only commit assets owned or licensed by KivuStack Ltd
* Do not add external remote resources or scripts in SVGs
