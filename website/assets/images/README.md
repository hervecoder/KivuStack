# Website Images — KivuSoft Ltd

This directory contains official **KivuSoft Ltd** website images deployed to GitHub Pages.

## Current assets

* `favicon.svg` — 32×32 KivuSoft icon favicon (based on `kivusoft-icon.svg`), `type="image/svg+xml"`
* `og-image.svg` — 1200×630 social preview graphic with `KivuSoft Ltd` and descriptor “Useful, reliable, and accessible technology”
* `kivusoft-logo.svg` — primary logo (icon + `KivuSoft` wordmark) for light backgrounds
* `kivusoft-logo-dark.svg` — logo variant for dark backgrounds
* `kivusoft-icon.svg` / `kivusoft-icon-dark.svg` — icon-only variants

All files are copies of the canonical assets in `/assets/` (`kivusoft-logo.svg`, `kivusoft-logo-dark.svg`, `kivusoft-icon.svg`, `kivusoft-icon-dark.svg`) and are kept in sync for deployment. The canonical brand documentation is `assets/brand-guidelines.md`.

## Intended contents

* Official logo files (approved)
* Approved product or team imagery
* Icons and illustrations owned by KivuSoft Ltd
* Social preview images

## Guidelines

* Use optimized formats (SVG preferred for logos/icons, WebP/AVIF for photos where appropriate)
* Keep files small and accessible (provide `alt` text where used)
* Only commit assets owned or licensed by KivuSoft Ltd
* Do not add external remote resources or scripts in SVGs
